# ТЗ: Telegram-бот «Список покупок с бюджетом»

## Проблема и аудитория
Люди забывают, что купить, и не видят, сколько выйдет в сумме. Аудитория — студенты и семьи, которые планируют покупки в магазине.

## Цель MVP (3 занятия)
Пользователь ведёт в Telegram личный список покупок с ценами и видит итоговую сумму.

## Функции MVP
| Команда | Что делает |
|---|---|
| `/start`, `/help` | приветствие и справка |
| `/add Название Цена` | добавляет товар (`/add Чай 100`, дробные: `99,5`) |
| `/list` | нумерованный список товаров |
| `/total` | сумма всех цен |
| `/clear` | очищает список пользователя |
| `/ask вопрос` | демо-ответ ИИ-заглушки (без внешнего API) |

## Не входит в MVP
Реальный ИИ-API, категории, общие списки, веб-интерфейс, валюты.

## Модули
- `bot.py` — handlers и форматирование ответов
- `db.py` — SQLite: `users`, `items` (список у каждого пользователя свой)
- `parser.py` — разбор строки «Название Цена»
- `ai.py` — офлайн-заглушка

## Нефункциональные требования
Токен только в `.env`; данные пользователей не логируются; тесты запускаются без интернета и токена (`python -m pytest -q`).

## Критерии приёмки
- Все команды из таблицы работают в Telegram.
- Неверный ввод (`/add Чай`, `/add Чай abc`, отрицательная цена) даёт подсказку формата, а не ошибку.
- У разных пользователей списки не пересекаются.
- Есть тесты на каждый модуль, все проходят.
