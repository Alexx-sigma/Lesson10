# Задачи (для GitHub Issues / Project)

Колонки Kanban: Backlog → In Progress → Review → Done. Каждая задача — своя ветка и свой PR.

| # | Название | Кто | Как проверить |
|---|---|---|---|
| 1 | Команда `/add` и разбор строки | C + A | `/add Чай 100` → «Добавлено»; тесты парсера зелёные |
| 2 | Таблица `items` и функции БД | B | `pytest tests/test_db.py` проходит |
| 3 | Команды `/list` и `/total` | A | пустой список → подсказка; сумма совпадает с ручной |
| 4 | Команда `/clear` | B + A | чужой список не удаляется (тест) |
| 5 | Команда `/ask` на ИИ-заглушке | C | пустой `/ask` даёт подсказку, не ошибку |
| 6 | Бюджет: `/budget 1000` и предупреждение о превышении (след. занятие) | вся команда | сумма > бюджета → предупреждение |

Шаблон: **Что сделать** · **Как проверить** · **Кто** · **Ветка** (`feature/...`).
