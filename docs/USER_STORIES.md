# User Stories

Роли в команде: **A** — bot.py, **B** — db.py, **C** — parser.py + ai.py. (Подставьте имена участников.)

## Участник A (bot.py)
1. Как покупатель, я хочу командой `/add Чай 100` добавить товар, чтобы не держать список в голове.
   - Критерий: бот отвечает «Добавлено: Чай — 100».
2. Как покупатель, я хочу видеть команды по `/help`, чтобы не учить их наизусть.
   - Критерий: в справке есть все команды из ТЗ.

## Участник B (db.py)
1. Как покупатель, я хочу, чтобы список сохранялся после перезапуска бота, чтобы не вводить его заново.
   - Критерий: товары лежат в SQLite и читаются `list_items`.
2. Как покупатель, я хочу очищать свой список командой `/clear`, чтобы начать новые покупки, не затрагивая чужие списки.
   - Критерий: `clear_items` удаляет только записи этого `telegram_id`.

## Участник C (parser.py, ai.py)
1. Как покупатель, я хочу писать цену с запятой (`99,5`), чтобы вводить так, как привычно.
   - Критерий: `parse_item_line("Чай 99,5")` → цена 99.5.
2. Как покупатель, я хочу получать понятную подсказку при ошибочном вводе, чтобы быстро его исправить.
   - Критерий: для `Чай`, `Чай abc`, `Чай -5` парсер возвращает `None`, бот показывает формат.
